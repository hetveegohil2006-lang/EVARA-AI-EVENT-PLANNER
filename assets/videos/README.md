# EVARA Platform Walkthrough Video

Place your video file in this directory to automatically mount it into the EVARA video player:

- **Filename:** `evara-walkthrough.mp4`
- **Supported Formats:** `.mp4`, `.webm`
- **Recommended Resolution:** 1920x1080 (1080p) or 1280x720 (720p)
- **Aspect Ratio:** 16:9

If this file is not present, EVARA automatically runs an interactive animated 4-chapter visual simulation walkthrough with real feature breakdowns, progress rail scrubbing, and full-screen support.
